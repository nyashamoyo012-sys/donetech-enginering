# DoneTech Engineering — GitHub Pages Website

## Publish on GitHub Pages

1. Create a new **public** GitHub repository, for example `donetech-engineering`.
2. Upload `index.html`, `style.css` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then **Save**.
6. Wait for GitHub to publish the site. Your URL will normally be:
   `https://YOUR-GITHUB-USERNAME.github.io/donetech-engineering/`

## Before publishing
Replace:
- `ADD EMAIL ADDRESS`
- `ADD PHONE NUMBER`
- `ADD HEAD-OFFICE ADDRESS`
- `YOUR_EMAIL@example.com` in the form action

Add the official Facebook URL if available.

## Odoo
Once GitHub Pages is live, copy the complete public website URL and use Odoo's website import-by-URL functionality if it is available in your Odoo version/database.
